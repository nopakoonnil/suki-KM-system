# ระบบบริหารจัดการร้านสุกี้ KM

ระบบสำหรับช่วยจัดการงานภายในร้านสุกี้ KM ให้เป็นระเบียบและสะดวกยิ่งขึ้น โดยรวบรวมข้อมูลสำคัญของร้านไว้ในที่เดียว

## วัตถุประสงค์

- ช่วยให้การจัดการร้านมีความเป็นระบบ
- ลดความผิดพลาดจากการบันทึกข้อมูลด้วยมือ
- สนับสนุนการติดตามยอดขาย วัตถุดิบ และการดำเนินงานของร้าน

## ขอบเขตการทำงาน

ระบบสามารถพัฒนาให้รองรับฟังก์ชันต่าง ๆ เช่น:

- **จัดการเมนูและราคา** — เพิ่ม แก้ไข และปิดจำหน่ายรายการอาหาร
- **จัดการคำสั่งซื้อ** — บันทึกรายการอาหารและติดตามสถานะการให้บริการ
- **จัดการวัตถุดิบและสต็อก** — ตรวจสอบปริมาณวัตถุดิบและแจ้งเตือนเมื่อใกล้หมด
- **จัดการยอดขาย** — บันทึกยอดขายและสรุปรายงานตามช่วงเวลา
- **จัดการข้อมูลพนักงาน** — จัดเก็บข้อมูลและกำหนดสิทธิ์การใช้งาน

> หมายเหตุ: รายการข้างต้นเป็นขอบเขตที่ระบบอาจรองรับในระหว่างการพัฒนา ฟังก์ชันที่ใช้งานได้จริงขึ้นอยู่กับความคืบหน้าของโครงการ

## ไฟล์ในโครงการ

| ไฟล์ | รายละเอียด |
| --- | --- |
| `index.html` | หน้าเว็บเริ่มต้นของโครงการ |

## เริ่มต้นใช้งาน

ขณะนี้สามารถเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์เพื่อดูหน้าเว็บเริ่มต้นได้ โดยดับเบิลคลิกไฟล์ หรือคลิกขวาแล้วเลือกเปิดด้วยเว็บเบราว์เซอร์

## เทคโนโลยี

- HTML

## สถานะโครงการ

โครงการอยู่ในระยะเริ่มต้น และสามารถเพิ่มเติมหน้าจอและฟังก์ชันการจัดการร้านในลำดับถัดไป
